Google Sheet

Enter the passcode once on each computer or phone to see the client list. It stays the same on all of them and in the Google Sheet.

Your passcode is short, so it could eventually be guessed. Change it to at least 12 characters (for example four unrelated words) under Apps Script → Project Settings → Script properties, then connect again.

Import clients

Import a CSV file (from Excel or Google Sheets). Clients are matched by name and their dates updated; anyone new is added.

Columns: First name, Last name, Last visit, Next due, Scheduled visit, Notes, On hold, Hold reason, Ended (Ended care or Deceased), Ended on. Dates like 11/17/2026 or 2026-11-17. A blank Next due is worked out from the last visit.
