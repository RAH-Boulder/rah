Using a shared computer?

Once connected, anyone who opens this page on this computer can see and change the list. Forget this computer erases the list and the passcode from this browser. Nothing is removed from the Google Sheet.

Spreadsheet file

Columns: First name, Last name, Last visit, Next due, Scheduled visit, Notes. Dates like 11/17/2026 or 2026-11-17. A blank Next due is worked out from the last visit.
